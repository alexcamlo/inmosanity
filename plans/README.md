## Findings considered and rejected

- **Footer `dangerouslySetInnerHTML`**: not elevated because both HTML values come from committed locale dictionaries, not CMS/request input. Revisit if the source becomes user- or CMS-controlled.
- **Hardcoded Sanity project/deployment identifiers**: treated as public configuration identifiers, not credentials. No secret value was copied into these plans.
- **`useCdn = false`**: documented design choice required for reliable webhook-driven Next cache freshness.
- **No live preview / generated Sanity types / Playwright**: explicitly documented as inactive or out of scope, not defects.
- **Broad removal of every apparently unused dependency**: rejected as unsafe because framework/Studio packages can be required implicitly. Plan 010 removes only confirmed-unused Vercel CLI and refreshes used tooling.
- **Immediate pagination build**: deferred. The query is capped at 50, but the planning build generated fewer than 50 property routes and there is no evidence users currently lose results. Re-audit when inventory approaches the cap.
- **Historical upgrade documents as stale active docs**: rejected because README and architecture documentation clearly label them as historical context rather than current runbooks.
